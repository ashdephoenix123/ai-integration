1. What are tools? 
Give the model access to external data and functions by attaching tools. Use built-in tools like web search or file search, or define your own for calling APIs, running code, or integrating with third-party systems.

TEXT Generation -
1. In addition to plain text, you can also have the model return structured data in JSON format—this feature is called Structured Outputs.
2. set instructions as a parameter to give model instruction to follow when generating response.
3. roles - 
    developer: another way to put an instruction parameter. prioritized ahead of user's message.
    user: end user request
    assistant: response generated by model has assistant role.


Image and Vision generation -  
1. use type: 'input_image' and the next key could be image_url or file_id or something else.
2. to use file_id we pass the file id and that file id can be created using files API.
3. model gives image result in base64 string then we convert it to Buffer data and then save that to device using fs.writeFileSync.
4. we use tools to geenerate an image, 
    ```bash

    tools: [{   type: 'image_generation' }]

    ```
5. detail: 'low' | 'high' | 'original' | 'auto'
